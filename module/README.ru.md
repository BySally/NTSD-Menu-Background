# NTSD Menu Background 0.1.2

Клиентский мод для Java 17 / Minecraft 1.20.1 / Forge 47.4.20 или 47.4.28. Заменяет два вызова отрисовки фона TitleScreen: вращающуюся панораму и её затеняющую накладку. Штатные экран, логотип, надписи и кнопки сохраняются. Другие экраны и мод начальной загрузки NTSD Early Loading не изменяются. На сервер мод не устанавливать.

## Файлы

- `mods/ntsd-menu-background-0.1.2.jar`
- `config/ntsd-menu/menu.properties`
- `config/ntsd-menu/orbital.ntsd`

```properties
enabled=true
sequence=orbital.ntsd
```

Для отключения поставить `enabled=false` либо убрать только этот клиентский мод с его конфигом. Никакие настройки Forge/кнопок/мира для отката не нужны. Если анимация отсутствует, повреждена или не декодируется, возвращается исходная панорама.

## Видео и ресурсы

Источник — предоставленный владельцем MP4 Orbital Sunrise, 2560×1440, 24 FPS, 216 кадров, 9 с. Встроенного MP4/H.264-декодера у Minecraft нет. Используется подготовленная из **всех** кадров индексированная последовательность JPEG с сохранением размеров и частоты. Прямого воспроизведения MP4 во время игры здесь нет. Конвертация с потерями JPEG q=2, 4:4:4; дополнительное сжатие сохраняет исходное разрешение, но не обещает побитовую идентичность цветовых значений.

Декодирование STBImage, уже входящим в Minecraft/LWJGL, выполняется в одном потоке. Ограниченный буфер: один ожидающий кадр и две переиспользуемые GPU-текстуры. Интерполяция соседних кадров выполняется на GPU. На 2560×1440 одна RGBA-текстура занимает 14,75 МБ, две — 29,49 МБ. С учётом ожидающего/обрабатываемого кадра и временного передаваемого кадра возможны ещё несколько буферов такого размера; весь ролик в RAM не разворачивается. Файл на диске около 96 МиБ. Нет зависимостей FancyMenu/WaterMedia/браузера/внешнего FFmpeg при запуске игры.

При уходе с TitleScreen декодер останавливается, файловый канал закрывается и текстуры удаляются. При возвращении воспроизведение начинается заново. Первый кадр предварительно готовится на этапе client setup, сам таймер запускается при первом отображении. При задержке декодера удерживается последний корректный кадр. Гарантировать плавность при остановке всего игрового процесса или драйвера невозможно.

Масштабирование `cover`: без растяжения, с центральной обрезкой. Для 5120×1440 исходник 16:9 обрезается сверху/снизу. Детали исходного 1440p не уменьшаются при подготовке. Исходная композиция на 32:9 целиком без полей не помещается.

## Исходники и сборка

Существующий кеш ForgeGradle 6, Gradle 8.8 и JDK 17:

```text
gradle --offline build
```

Либо использовать поставленный в локальной developer-копии Gradle wrapper: `gradlew.bat --offline build`. Это штатный ForgeGradle `reobfJar`. Mixin содержит привязанные к 1.20.1 имена SRG двух фоновых вызовов. Другие версии Minecraft не поддерживаются; обновление Forge требует повторной проверки.

Подготовка ресурса выполняется отдельно скриптом `prepare_video.py` с FFmpeg/ffprobe в PATH:

```text
python prepare_video.py source.mp4 orbital.ntsd
```

Этот скрипт не перезаписывает существующие выходные файлы. Исходник не меняется. Формат совместим с индексом NTSD Early Loading: magic `NTSDFR01`, big-endian размеры/FPS/число кадров, индекс offset/size/CRC32, затем JPEG. Таймер меню идёт по кругу без ping-pong, в исходном направлении.

## Диагностика и проверка

Редакция 0.1.2 исправляет повреждение кадров после загрузки интерфейсных текстур: перед каждой передачей плотно упакованного RGBA-кадра задаются собственные GL_UNPACK_ROW_LENGTH, SKIP_ROWS, SKIP_PIXELS, ALIGNMENT и PIXEL_UNPACK_BUFFER. Предыдущие значения восстанавливаются в finally. Штатные кнопки, жизненный цикл экранов, иконка, подпись автора и сам файл анимации не меняются.

Дополнительный флаг `-Dntsd.menu.returnVerify=true` предназначен только для изолированного тестового профиля: сравнивает CRC декодированного кадра с фактическими пикселями GPU, проверяет восстановление unpack-состояния, делает снимки HD/QHD/ultrawide и шесть раз возвращается через штатный onClose() экранов настроек, серверов, модов и языков. Результат — `ntsd-return-verification/result.json`; после сценария игра закрывается. По умолчанию флаг выключен: нет чтения текстуры обратно с GPU, автоматических переходов или снимков экрана.

`logs/ntsd-menu.properties` содержит счётчики и последнюю ошибку. Опциональный флаг JVM `-Dntsd.menu.verify=true` включает **только тестовый** сценарий: снимки QHD/ultrawide, цикл, переходы по штатным кнопкам и выход из игры. Обычным игрокам его не добавлять. По умолчанию он выключен. `-Dntsd.menu.disabled=true` принудительно отключает фон для сравнения; `ntsd.menu.expectFallback` используется только с намеренно повреждённым тестовым ресурсом.
